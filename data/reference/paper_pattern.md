# NBE Junior Assistant — Exact Paper Pattern

## Exam Structure
- Total Questions: 200
- Total Marks: 200
- Total Time: 180 minutes
- Mode: Computer Based Test

## Sections
1. General Intelligence & Reasoning — 50 Qs — 50 Marks
2. General Awareness — 50 Qs — 50 Marks
3. Quantitative Aptitude — 50 Qs — 50 Marks
4. English Comprehension — 50 Qs — 50 Marks

## Marking Scheme (MANDATORY)
- Correct answer: +1.00
- Wrong answer: -0.25
- Unanswered: 0.00

## Scoring Formula
Score = (Correct × 1) - (Wrong × 0.25)

## Qualifying Target
- Target practice score: 150+ raw marks (after negative marking)

## Attempt Strategy Notes for Platform
- Show live estimated score if possible
- On results screen, show:
  - Correct count
  - Wrong count
  - Unanswered count
  - Final score with negative marking applied
  - Accuracy %
  - Section-wise net score

## Source Mapping
Because NBE PYQs are scarce, generate mocks from:
- SSC CHSL Tier-1
- SSC MTS
- DSSSB Junior Assistant / LDC
- SSC Selection Post
- NBE 2015 Junior Assistant paper (highest priority reference style)

## Difficulty Filter
- Quant should prefer arithmetic + basic algebra
- Avoid overly advanced geometry/trigonometry heavy items when possible
